# Data card template — AI Clinician

## Governance and context of use

Record the data controller, ethics/DUA approvals, approved compute boundary, prohibited uses, extraction date, source-system versions, and accountable data steward. Never include patient identifiers, patient-level manifests, filenames containing identifiers, or source text.

## Cohort construction

Document the mCRC eligibility definition, index decision date, exclusions, seven-table linkage results, missing/duplicate quarantine counts, date range, temporal 70/15/15 patient split, and all deviations from the registered protocol.

## Data quality

Report aggregate missingness, timeline completeness, conflict prevalence, source-availability completeness, treatment-class support, outcome availability, censoring, OOD definition, and subgroup representation. Bind every table to a snapshot hash and preprocessing version.

## Validation and limitations

Attach the locked timeline-quality report, leakage audit, known measurement error, suspected informative missingness, single-center transportability limits, and downgrade decision if the timeline gate failed.
